# 🧠 Personal Knowledge Vault — Landing Page

A clean, fully responsive **product landing page** for *Personal Knowledge Vault* — a fictional second-brain app designed to help users structure their thinking, connect ideas, and turn learning into long-term knowledge.

Built as a front-end assignment using pure HTML and CSS.

## 🌐 Live Demo

👉 [View Live Site](https://tomal5085.github.io/ASSIGNMENT-001/)

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure and semantic markup |
| **CSS3** | Styling, layout (Flexbox & Grid), responsiveness |
| **Google Fonts – Inter** | Typography |
| **Font Awesome 7** | Icons (play button, social media, checkmarks, etc.) |

---

## ✨ Key Features

- **Sticky Navbar** — Logo, nav links, and an "Get Early Access" CTA button
- **Hero Banner** — Full-width background image with overlay, badge, headline, and dual CTA buttons
- **Problem Section** — Four pain-point cards (Scattered Notes, Bookmark Overload, No Idea Connections, Forgetting)
- **Solution / Second Brain Section** — Side-by-side layout with a knowledge visualization image and a checklist of features
- **Early Access CTA** — Centered call-to-action block with a conversion-focused button
- **Footer** — Branded logo, social media links (X/Twitter, LinkedIn, Facebook), and copyright

---

## 📦 Dependencies

This is a **zero-dependency** static project. External resources are loaded via CDN:

```html
<!-- Google Fonts -->
<link href="https://fonts.googleapis.com/css2?family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&display=swap" rel="stylesheet">

<!-- Font Awesome 7 -->
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.0.1/css/all.min.css">
```

No `npm install` required. No build process.

## 🚀 Running Locally

Since this is a plain HTML/CSS project, you just need a browser:

**Option 1 — Open directly**
```bash
git clone https://github.com/TOMAL5085/ASSIGNMENT-001.git
cd ASSIGNMENT-001
# Open index.html in your browser
```

**Option 2 — Use VS Code Live Server (recommended)**
1. Clone the repo (same as above)
2. Open the folder in [VS Code](https://code.visualstudio.com/)
3. Install the [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)
4. Right-click `index.html` → **Open with Live Server**
